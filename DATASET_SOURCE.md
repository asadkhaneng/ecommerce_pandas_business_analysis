# Dataset source record

Dataset: Brazilian E-Commerce Public Dataset by Olist

Canonical source: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

Verified direct-access alternatives:
- Hugging Face parquet representation: https://huggingface.co/datasets/miminmoons/olist-ecommerce-for-delivery-and-review-prediction
- Public GitHub CSV mirror used to prepare the local offline copies: https://github.com/Ganesh7699/Brazilian-E-Commerce-OList

The original data is anonymized commercial e-commerce data describing approximately 100,000 orders from 2016 to 2018. The local package contains eight CSV files used by the notebook.
